## ✨ Features

- **Convert PDFs**: Convert from DOCX, text, and images to PDF seamlessly.
- **Split & Merge**: Easy manipulation of PDF pages.
- **Compress**: Optimize PDF size locally without uploading to a server.
- **Media Tools**: Handle various media files and generate presentations.
- **AI Powered**: Integrated with Gemini API for smart processing.

## 🚀 Run Locally

**Prerequisites:**  Node.js (v18+)

1. Install the required dependencies:
   ```bash
   npm install
   ```

2. Set up your environment variables. Open `.env.local` (or create it) and add your Gemini API key:
   ```bash
   GEMINI_API_KEY=your_api_key_here
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
